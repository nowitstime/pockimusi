# Roller — feedback

Pitched note repeat (PHASE_L.md L5). Hold `B` (1/16), `A` (1/8), `Y` (1/8T) or `X` (1/16 with the off-beats accented) and the note repeats on the grid; the D-pad and shoulders set the next repeat's note and octave; `L1 + R1` doubles the rate.

## Questions for the pass

1. Can you play a rolling drum and bass line at 174 that changes notes in time with the chords?
2. `X`'s accents: is "off-beats louder" the rolling feel, or should it be a different pattern (e.g. accents on 1 and the "a")?
3. `LENGTH`: are `SHORT` / `HALF` / `FULL` the right three? Does `FULL` on `REESE` sound like one long note (it should still re-attack)?
4. Is a roll that starts on the next step (a press between steps) too late at slow tempos?
5. Which patches suit it best? (`REESE`, `DNB SUB`, `PLUCK`, `STAB`, `SUPERSAW`...)
6. With `PUMP` on, does a 1/16 roll breathe with the kick?
