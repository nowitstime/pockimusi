## How it plays

| Control | Job |
| :-- | :-- |
| `B A Y X` | Pads, as on Drums |
| D-pad `↑ ↓ ← →` | The same four pads by position: `↑` = `X`, `↓` = `B`, `←` = `Y`, `→` = `A`. A diagonal hits two |
| `L1` | Ghost: soft, short |
| `R1` | Accent: loud, longer |
| `L1 + R1` | Note repeat at 1/16 (1/12T on a triplet grid) |
| Rows | As Drums: kit, pad sounds, `VARIATION`, `TUNE`, `LEVEL` |

No flam or ratchet (those are on Drums' D-pad). Swapping with Drums keeps the notes.
