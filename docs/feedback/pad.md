## How it plays

| Control | Job |
| :-- | :-- |
| `B` | Full chord (four notes, with the harp's colour) |
| `A` | Open: root, fifth, octave |
| `Y` | High: fifth, octave, third above |
| `X` | Swell: the full chord, fading in slowly |
| Buttons | Layer: hold several at once |
| D-pad `↑ / ↓` | Brightness; stays where it's left, recorded |
| D-pad `← / →` | Movement (drift and shimmer); stays where it's left, recorded |
| `L1 / R1` | Octave down / up |
| Rows | `PATCH` (opens on `WARM`; sounds with a loop only), `FOLLOW`, `ATTACK`, `RELEASE` |

- [ ] Can I set it going and leave it? Or does it need a thumb held for the whole loop?

- [ ] Is a drone (one note through every chord) wanted?
- [ ] Is a pulsing pad (gated, ducked by the kick) wanted?
